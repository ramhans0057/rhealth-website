# Rhealth — Ramhans Bone and Joint Clinic

Static GitHub Pages website. All site files are included.

## Publish
1. Upload `index.html`, `schedule.json`, and the `assets` folder to the root of `ramhans0057/rhealth-website`.
2. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
3. Open https://ramhans0057.github.io/rhealth-website/

## Daily schedule updates
Edit `schedule.json` directly in GitHub and click **Commit changes**.
Change `todayNotice`, `openingHours`, `consultationHours`, `xrayHours`, and `lastUpdated` as needed. GitHub Pages republishes automatically. Use valid JSON with quotes and commas.

## Verify before publishing
Confirm clinic phone (signboards show different numbers), address, exact spelling of doctors' names, clinical qualifications, services and legal scope, fee, hours, and WhatsApp number. No live appointment backend is included yet. The appointment button leads to contact information.

The logo is a crop of the original supplied signboard, not a reconstructed logo.
